# Integrate Mastra in your Express project

There are two main ways to integrate Mastra with your Express application: as a separate backend service or directly integrated into your Express app.

## 1. Separate Backend Integration

Best for larger projects where you want to:
- Scale your AI backend independently
- Keep clear separation of concerns
- Have more deployment flexibility

### Use MastraClient

Create a client instance and use it in your Express application:

```typescript filename="lib/mastra.ts" copy
import { MastraClient } from '@mastra/client-js';

// Initialize the client
export const mastraClient = new MastraClient({
  baseUrl: process.env.MASTRA_API_URL || 'http://localhost:4111',
});
```

Example usage in your Express route:

```typescript filename="routes/weather.ts" copy
import express from 'express';
import { mastraClient } from '../lib/mastra';

const router = express.Router();

router.post('/weather', async (req, res) => {
  try {
    const { city } = req.body;
    const agent = mastraClient.getAgent('weatherAgent');
    
    const response = await agent.generate({
      messages: [{ role: 'user', content: `What's the weather like in ${city}?` }],
    });
    
    res.json({ result: response.text });
  } catch (error) {
    console.error('Error:', error);
    res.status(500).json({ error: 'An error occurred' });
  }
});

export default router;
```

## 2. Direct Integration

Better for smaller projects or prototypes. This approach bundles Mastra directly with your Express application.

<Steps>
### Initialize Mastra in your Express Project

First, navigate to your Express project root and initialize Mastra:

```bash copy

```

Then run the initialization command:

### Configure Express App

Create your Express app with Mastra integration:

```typescript filename="app.ts" copy
import express from 'express';
import { mastra } from './mastra';

const app = express();
const port = process.env.PORT || 3000;

// Middleware
app.use(express.json());

// Basic route
app.get('/', (req, res) => {
  res.send('Express + Mastra Integration');
});

// Example route using Mastra
app.post('/api/weather', async (req, res) => {
  try {
    const { city } = req.body;
    const agent = mastra.getAgent('weatherAgent');
    
    const response = await agent.generate({
      messages: [
        {
          role: 'user',
          content: `What's the weather like in ${city}?`,
        },
      ],
    });
    
    res.json({ result: response.text });
  } catch (error) {
    console.error('Error:', error);
    res.status(500).json({ error: 'An error occurred' });
  }
});

// Example streaming route
app.post('/api/weather/stream', async (req, res) => {
  try {
    const { city } = req.body;
    const agent = mastra.getAgent('weatherAgent');
    
    const result = await agent.stream({
      messages: [
        {
          role: 'user',
          content: `What's the weather like in ${city}?`,
        },
      ],
    });
    
    // Return the stream directly as a Response object
    return new Response(result.body);
  } catch (error) {
    console.error('Error:', error);
    res.status(500).json({ error: 'An error occurred' });
  }
});

// Start the server
app.listen(port, () => {
  console.log(`Server running at http://localhost:${port}`);
});
```

### Middleware Example

You can create a Mastra middleware for Express to handle AI-related functionality:

```typescript filename="middleware/mastra-middleware.ts" copy
import { Request, Response, NextFunction } from 'express';
import { mastra } from '../mastra';

// Extend the Express Request type
interface MastraRequest extends Request {
  mastraAgent: any;
}

// Middleware to inject Mastra agent into request object
export const mastraMiddleware = (agentName: string) => {
  return (req: MastraRequest, res: Response, next: NextFunction) => {
    try {
      // Attach the specified agent to the request object
      req.mastraAgent = mastra.getAgent(agentName);
      next();
    } catch (error) {
      console.error('Error initializing Mastra agent:', error);
      res.status(500).json({ error: 'Failed to initialize AI agent' });
    }
  };
};
```

Usage in routes:

```typescript filename="routes/ai-routes.ts" copy
import express, { Request } from 'express';
import { mastraMiddleware } from '../middleware/mastra-middleware';

// Extend the Express Request type to include mastraAgent
interface MastraRequest extends Request {
  mastraAgent: any;
}

const router = express.Router();

// Apply the middleware to specific routes
router.post('/analyze', mastraMiddleware('textAnalysisAgent'), async (req: MastraRequest, res) => {
  try {
    const { text } = req.body;
    
    // Use the agent that was attached by the middleware
    const result = await req.mastraAgent.generate({
      messages: [{ role: 'user', content: `Analyze this text: ${text}` }],
    });
    
    res.json({ analysis: result.text });
  } catch (error) {
    console.error('Error:', error);
    res.status(500).json({ error: 'An error occurred' });
  }
});

export default router;
```

### Deployment

When using direct integration, your Mastra instance will be deployed alongside your Express application. Ensure you:
- Set up environment variables for your LLM API keys in your deployment platform
- Implement proper error handling for production use
- Monitor your AI agent's performance and costs
</Steps>

## Observability

Mastra provides built-in observability features to help you monitor, debug, and optimize your AI operations. This includes:
- Tracing of AI operations and their performance
- Logging of prompts, completions, and errors
- Integration with observability platforms like Langfuse and LangSmith

For detailed setup instructions and configuration options specific to Express local development, see our [Observability Configuration Guide](/docs/observability/observability).
