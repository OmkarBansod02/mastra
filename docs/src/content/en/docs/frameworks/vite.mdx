# Integrate Mastra in your Vite project

There are two main ways to integrate Mastra with your Vite application: as a separate backend service or directly integrated into your Vite app.

## 1. Separate Backend Integration

Best for larger projects where you want to:
- Scale your AI backend independently
- Keep clear separation of concerns
- Have more deployment flexibility

### Use MastraClient

Create a client instance and use it in your Vite application:

```typescript filename="src/lib/mastra.ts" copy
import { MastraClient } from '@mastra/client-js';

// Initialize the client
export const mastraClient = new MastraClient({
  baseUrl: import.meta.env.VITE_MASTRA_API_URL || 'http://localhost:4111',
});
```

<Callout type="info">
  Note that in Vite, environment variables must be prefixed with `VITE_` to be exposed to the client.
</Callout>

### Example React Component

Here's an example usage with React in your Vite app:

```tsx filename="src/components/WeatherWidget.tsx" copy
import { useState } from 'react'
import { mastraClient } from '../lib/mastra'

export function WeatherWidget() {
  const [city, setCity] = useState('')
  const [response, setResponse] = useState('')
  const [loading, setLoading] = useState(false)

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault()
    setLoading(true)
    
    try {
      const agent = mastraClient.getAgent('weatherAgent')
      const result = await agent.generate({
        messages: [{ role: 'user', content: `What's the weather like in ${city}?` }],
      })
      
      setResponse(result.text)
    } catch (error) {
      console.error('Error:', error)
      setResponse('Failed to get weather information')
    } finally {
      setLoading(false)
    }
  }

  return (
    <div className="weather-widget">
      <form onSubmit={handleSubmit}>
        <input 
          value={city}
          onChange={(e) => setCity(e.target.value)}
          placeholder="Enter city name" 
        />
        <button type="submit" disabled={loading}>
          {loading ? 'Loading...' : 'Get Weather'}
        </button>
      </form>
      
      {response && (
        <div className="response">
          <h3>Weather Information:</h3>
          <p>{response}</p>
        </div>
      )}
    </div>
  )
}
```

### Configure Vite Proxy for Development

For local development, use Vite's proxy feature to avoid CORS issues:

```javascript filename="vite.config.js" copy
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react' // or vue, svelte, etc.

export default defineConfig({
  plugins: [react()],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:4111',
        changeOrigin: true,
      },
    },
  },
})
```

### Deployment

When you're ready to deploy, you'll need to:

1. Deploy your Mastra backend to a server or serverless platform
2. Deploy your Vite frontend to a static hosting service
3. Configure your production environment variables to point to your Mastra backend URL

Popular deployment options for Vite apps include:
- Vercel, Netlify, or GitHub Pages for the frontend
- Railway, Render, or Fly.io for the Mastra backend

</Steps>

### Create a Simple API Server

Since Vite doesn't include a server runtime like Next.js, create a simple Express server:

```bash copy
npm install express cors
npm install -D @types/express @types/cors
```

Create a server file:

```typescript filename="server.ts" copy
import express from 'express';
import cors from 'cors';
import { mastra } from './mastra';

const app = express();
const port = process.env.PORT || 4111;

app.use(cors({
  origin: 'http://localhost:5173', // Default Vite dev server port
  methods: ['GET', 'POST'],
}));

app.use(express.json());

// Create an endpoint for agent generation
app.post('/api/agents/:agentId/generate', async (req, res) => {
  try {
    const { agentId } = req.params;
    const { messages } = req.body;
    
    const agent = mastra.getAgent(agentId);
    const result = await agent.generate({ messages });
    
    res.json({ text: result.text });
  } catch (error) {
    console.error('Error:', error);
    res.status(500).json({ error: 'Failed to generate response' });
  }
});

app.listen(port, () => {
  console.log(`Mastra server listening at http://localhost:${port}`);
});
```

Add a script to your `package.json`:

```json filename="package.json" copy
{
  "scripts": {
    "dev:frontend": "vite",
    "dev:backend": "tsx watch server.ts",
    "dev": "concurrently \"npm run dev:frontend\" \"npm run dev:backend\""
  }
}
```

### Connect to Your API

Create a simple client utility:

```typescript filename="src/lib/mastra-client.ts" copy
export class MastraClient {
  private baseUrl: string;
  
  constructor(baseUrl = '') {
    this.baseUrl = baseUrl || '/api';
  }
  
  // Get agent by ID
  getAgent(agentId: string) {
    return {
      // Generate a complete response
      generate: async (params: { messages: { role: string; content: string }[] }) => {
        const response = await fetch(`${this.baseUrl}/agents/${agentId}/generate`, {
          method: 'POST',
          headers: {
            'Content-Type': 'application/json',
          },
          body: JSON.stringify(params),
        });
        
        if (!response.ok) {
          throw new Error(`Failed to generate: ${response.statusText}`);
        }
        
        return response.json();
      }
    };
  }
}

// Create and export a default client instance
export const mastraClient = new MastraClient();
```

### Deployment

When deploying your Vite application with Mastra:

1. Build your Vite app with `vite build`
2. Deploy the frontend to a static hosting service (Netlify, Vercel, etc.)
3. Deploy your Express server to a Node.js hosting platform
4. Configure environment variables to connect the frontend to your backend

</Steps>

## Environment Variables in Vite

<Callout type="info">
In Vite, client-side environment variables must be prefixed with `VITE_` to be accessible in your code.
</Callout>

Example `.env.development` file:
```bash filename=".env.development" copy
VITE_MASTRA_API_URL=http://localhost:4111
```

Access in your code with:
```js
const apiUrl = import.meta.env.VITE_MASTRA_API_URL
```
